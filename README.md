# Orbit releases

Downloadable builds of **Orbit**, a personal command center for the Mac (menu bar launcher, tasks and notes, currency, clock, Mac maintenance). This repository only holds the builds; Orbit's in-app update check reads the latest release here.

## Install
1. Open the [latest release](../../releases/latest) and download `Orbit-<version>.zip`.
2. Unzip it and move `Orbit.app` to your Applications folder.
3. The builds are not notarized by Apple. The first time you open Orbit, macOS will refuse; go to **System Settings → Privacy & Security** and choose **Open Anyway**.

Requires macOS 14 or later.

## Good to know
- **Updating:** Orbit tells you when a newer version is published (Settings → Updates) and opens its release page. Download it and replace the app in Applications. Orbit never downloads or installs anything by itself.
- **Widgets** show "Open Orbit to sync" in these builds, because sharing data with a widget needs an Apple developer team in the signature.
- macOS may ask again for permissions (notifications, microphone, Full Disk Access) after an update.

# Versões do Orbit (pt-BR)

Builds para download do **Orbit**, uma central de comando pessoal para o Mac. Este repositório guarda só os builds; a verificação de atualização do app lê a última versão publicada aqui.

1. Abra a [última versão](../../releases/latest) e baixe `Orbit-<versão>.zip`.
2. Descompacte e mova o `Orbit.app` para a pasta Aplicativos.
3. Os builds não são notarizados pela Apple. Na primeira abertura o macOS recusa; vá em **Ajustes do Sistema → Privacidade e Segurança** e escolha **Abrir Mesmo Assim**.

Requer macOS 14 ou mais recente. Para atualizar, o Orbit avisa em Ajustes → Updates e abre a página da versão; baixe e substitua o app. Nestes builds os widgets mostram "Open Orbit to sync".
